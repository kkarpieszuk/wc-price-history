# Database Migration: Move Price History from Post Meta to Custom Tables

## Summary

This PR implements a comprehensive database migration system to move price history data from WordPress post_meta to dedicated custom database tables, significantly improving query performance and scalability.

## Changes

### New Features

- **Custom Database Tables**: Created two new tables (`wp_wc_price_history` and `wp_wc_price_history_meta`) for storing price history
- **Migration System**: Automated AJAX-based batch migration from post_meta to tables
- **Progress Tracking**: Real-time progress bar showing migration status
- **Migration Notices**: Admin notices similar to WooCommerce database update flow
- **Backward Compatibility**: Seamless fallback to post_meta for existing installations

### Technical Details

#### Database Schema

**Main Table: `wp_wc_price_history`**
- Stores price history with support for both regular and sale prices
- Includes `previous_price` and `previous_sale_price` columns for price comparison
- UNIQUE constraint on (`product_id`, `date_gmt`) prevents duplicate entries
- Optimized indexes for efficient querying

**Meta Table: `wp_wc_price_history_meta`**
- Stores additional metadata about price changes
- Supports metadata like `was_on_sale` and `change_reason` for manual price edits

#### Migration Process

1. Automatic detection of products with existing price history in post_meta
2. AJAX-based batch processing (10 products per batch)
3. Real-time progress bar with percentage and product count
4. Safeguards against duplicate migration (application + database level)
5. Preserves post_meta data as backup

- `app/PriorPrice/Database/Install.php` - Table creation and schema management

- `app/PriorPrice/Database/AdminNotice.php` - Admin UI for migration notices

- `assets/js/migration.js` - AJAX migration handlers with progress tracking
- `assets/css/migration.css` - Styling for migration UI

#### Key Files Modified

- `app/PriorPrice/HistoryStorage.php` - Adapter pattern supporting both post_meta and tables
- `app/PriorPrice/Ajax.php` - Added migration AJAX endpoint
- `app/PriorPrice/AdminAssets.php` - Enqueues migration scripts and styles

- `plugin.php` - Activation hooks and table creation

## Benefits

1. **Performance**: Database queries are significantly faster than post_meta lookups
2. **Scalability**: Better handling of large product catalogs with extensive history
3. **Flexibility**: Added columns for previous prices enable better price comparison features
4. **User Experience**: Smooth migration process with clear progress indicators
5. **Data Integrity**: Multiple safeguards prevent duplicate or lost data during migration

## Database Migration Status

The migration system tracks status using WordPress options:
- `wc_price_history_db_version` - Current database version (2.0.0)
- `wc_price_history_migration_status` - Status (pending/in_progress/completed/not_needed)
- `wc_price_history_migration_total` - Total products to migrate
- `wc_price_history_migration_processed` - Products migrated so far
- `wc_price_history_migrated_products` - Array of migrated product IDs

## Backward Compatibility

- Existing installations continue working with post_meta until migration is triggered
- Plugin automatically detects whether to use tables or post_meta
- Post_meta data is preserved as backup after migration
- Can handle rollback if needed
